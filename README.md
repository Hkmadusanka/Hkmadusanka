## 👋 About Me

I'm **Kavinda Madusanka**, a WordPress-focused Web Developer passionate about building professional websites and useful digital experiences.

My main focus is **WordPress website development**, from business websites and landing pages to e-commerce experiences. I also work with modern frontend technologies to build custom interfaces and web applications.

I use AI-assisted development tools to help explore solutions, improve coding workflows, debug problems, and turn ideas into working projects.

- 🌐 **WordPress Development:** Business websites, Elementor, landing pages, e-commerce and customization.
- 🎨 **Frontend Development:** HTML, CSS, JavaScript, Tailwind CSS, React and Next.js.
- 🗄️ **Backend & Data:** Supabase and SQL.
- 📱 **Application Development:** Exploring web and mobile application projects.
- 🤖 **AI-Assisted Workflow:** AI-supported coding, debugging, prototyping and problem solving.
- 🎓 **Education:** Higher National Diploma in Information Technology (HNDIT).

> I believe great websites combine thoughtful design, useful functionality and a clear understanding of what people need.
