## 👋 About Me

I'm **Kavinda Madusanka**, a WordPress-focused Web Developer who enjoys building modern digital experiences for businesses and brands.

My primary focus is **WordPress website development**, including business websites, landing pages, custom website solutions, and e-commerce platforms. I also work with modern frontend technologies to develop custom interfaces and web applications.

- 🌐 **WordPress:** Website development, Elementor, customization and e-commerce.
- ⚡ **Frontend:** HTML, CSS, JavaScript, Tailwind CSS, React and Next.js.
- 🗄️ **Backend & Data:** Supabase and SQL.
- 🤖 **AI-Assisted Development:** Using AI tools to accelerate development, explore solutions, debug code and build practical projects.
- 📱 **Application Development:** Exploring modern web and mobile application solutions.
- 🎓 **Education:** Higher National Diploma in Information Technology (HNDIT).

**My approach:** Combine the flexibility of WordPress, modern web technologies and AI-assisted workflows to build useful, responsive and maintainable digital products.
